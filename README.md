# Flutter Learning Projects

A collection of Flutter projects created while learning cross-platform mobile application development using Flutter and Dart.

## Projects

### 1. Student Task Manager

A simple Flutter application for managing student tasks.

#### Features

- Add new tasks
- Prevent empty task entries
- Display tasks in a dynamic list
- Delete tasks
- Show a live task counter
- Display SnackBar feedback when a task is added
- Show an empty-state message when no tasks are available

#### Concepts Practiced

- Flutter widgets
- StatelessWidget and StatefulWidget
- State management using `setState()`
- User input with `TextField` and `TextEditingController`
- Event handling
- Input validation
- Dynamic lists using `ListView.builder`
- Basic Flutter UI layout
- Widget testing

#### Technologies

- Flutter
- Dart
